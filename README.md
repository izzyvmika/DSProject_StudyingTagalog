# DSProject_StudyingTagalog
DS Project to see if studying Tagalog via specific course for 20 min/day significantly changes % of words understood over 2 weeks.

**Files:**
* Stats Tracking (for R Dataset) - Contains the dataset used for analysis. Tracks each word in a sentence, the guess, whether the guess is correct, and whether to track (Keep) that word (this is to filter out eg most function words, proper nouns).

* Tagalog Sentences - For reference - the original sentences recorded/written down each day.

* Data Science Project (.pdf / .rmd file) - The code/data analysis & initial report.

* Data 211 Project Presentation - The PowerPoint / presentation file.
